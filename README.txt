SOLO Electronic Menu
====================

1) Open index.html in a browser to preview.
2) Demo items and prices are placeholders. Edit the `products` array in index.html.
3) To enable WhatsApp ordering, search for `249000000000` in index.html and replace it with the restaurant WhatsApp number including country code, without the + sign.
4) This is a static HTML/CSS/JavaScript site and can be hosted on GitHub Pages.
5) Images currently use remote image URLs. Pinterest search boards are provided separately as inspiration references; use only images you have permission to publish commercially. To replace a photo, change the `img` URL for the relevant product.
